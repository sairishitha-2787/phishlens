# Phishlens — live sprint checklist

This is the Phishlens team's live sprint checklist for the *Detecting AI-Generated Phishing Content* project (Rishitha, Poojitha & Vedha Sri, Woxsen University). It is a single self-contained static HTML page — `index.html` — kept in sync across everyone viewing it via Firebase Firestore, so a task ticked by one teammate shows up for the others. There is no build step: open the page directly, or serve it from GitHub Pages as-is.
